- 構成：大福帳 → 集計テーブル 5 本（SQL 班）→ 問題テーブル QZ_QUESTIONS（固定 10 問＋AI 生成）→ Streamlit（画面 1 枚）→ 回答テーブル QZ_ANSWERS
- AI：`SNOWFLAKE.CORTEX.COMPLETE(model, prompt)` を SQL から呼ぶ（朝の確認で通ったモデル）。用途は 2 つ。①出題＝集計表（数十行）を渡して「直感と逆になりそうな組」を JSON で 5 つ返させる ②解説＝正解の数字を渡して 2 行の解説文。**正解の判定はプログラム（値の比較）**。AI の JSON は検証してから INSERT
- CoCo（Cortex Code）はアプリ内では使えない（開発者用の CLI）。アプリ内の AI は COMPLETE
- 画面：左サイドバー＝名前・デッキ・モード・スコア・連勝・ランキング／中央＝問題 → 回答ボタン → 答え合わせ（数字・棒または折れ線・解説）→「使った SQL」「定義」の折りたたみ → 次の問題／下＝「AI に新しい問題を作らせる」ボタン
- 虫食いの作り方：週次（または月次）の系列から連続 k 点（月次 3 点／週次 8 点）を隠す。候補 4 つ＝正解＋他カテゴリの同じ区間 3 つ。**min-max で正規化して形だけ比べる**（スケールで答えが割れないように）。答え合わせで元の系列と「他の 3 つは何のカテゴリだったか」を出す
- High & Low の作り方：集計表から 2 行を引き「A の {指標} は B より高い？低い？」。差 3% 未満の組は出さない（引き分け回避）
- 定義（画面に表示）：注文＝顧客 ID×購入日時／平均購入単価＝売上÷注文数／優良顧客＝Day3 の RFM（化粧品購入者で R・F・M 高、2,865 人）／カテゴリ異物（13ページ目・.tsv.gz・3Dプリンター>その他）＝「カテゴリ不明」として比較から除外／Apple Gift Card＝独立扱い（チーム決定に合わせる）
